\section{Inequacions}
Resoldre els següents exercicis 
\subsection{Primer apartat}
Trobau el conjunts de punts que satisfà la següent inequació 
\[
|x-|x-2|| < 3
\]
Dividim entre els casos 

\begin{enumerate}
\item $x<2$
\[
|x-2|= -x + 2 
|x-(-x+2)| < 3 \Longrightarrow |x+x -2| < 3 
\]
Aplicam la definició del valor absolut: 
\[ 
-3<x+x-2<3 \Longrightarrow -3<2x-2<3
\]
Sumam 2 per cada costat
\[
-1<2x<5
\]
Dividim entre 2
\[
\dfrac{-1}{2}<2x<\dfrac{5}{2}
\]
\item $x\geq2$
\[
|x-x-2| < 3 
|-2| < 3 
\]
Funciona per tot $x\geq2$

\end{enumerate}
\textbf{Solució}
\[
x \in (\tfrac{-1}{2},\tfrac{5}{2})\cup[2,\infty) \Longrightarrow x\in (\tfrac{-1}{2},\infty)
\]
\subsection{Segon apartat}
Determinau el conjunts de punts que satisfà la següent inequació en funció de $a\in (\mathbb{R} $
\[
x^2 -ax \leq 2
\]
\begin{enumerate}
\item Restam $2$
\[
x^2 -ax -2 \leq 0
\]
\item Igualam la equació:
\[
x^2 -ax -2 = 0
\]
\item Resolem l'equació de segon grau 
\[
x1 = \dfrac{a + \sqrt{a^2+8}}{2}
\]
\[
x2 = \dfrac{a- \sqrt{a^2+8}}{2}
\]
\end{enumerate}
Resultat final: 
\[
\dfrac{a - \sqrt{a^2+8}}{2} < x < \dfrac{a + \sqrt{a^2+8}}{2}
\]
